
# KerjaDekat

Solusi untuk membantu para pencari pekerja untuk mencari pekerjaan yang sesuai, dan pas. juga membantu perushaan mencari pekerja dengan cepat!
## Tujuan Project

- Menuntaskan masalah susahnya mencari pekerjaan, dan mendapatkan pekerja
- Untuk membantu perushaan mencari pekerja



## Features

- Halaman utama menampilkan lowongan pekerjaan yang tersedia
- Mencari pekerjaan berdasarkan nama perushaan / nama pekerjaan (Belum Diimlementasikan)
- Perushaan dapat mengupload lowongan yang dibutuhkan



## Tech Stack

**Client:** Mobile app - Kotlin

**Server:** Node, Express
